# mihomo 归档（config_old）

只存**历史版本**快照，不含现役版本（与姊妹仓口径一致：现役在 `clash/profiles/` 下。

命名：`routing_vX.Y.yaml` / `routing_vX.Y.min.yaml`、`lazy_vX.Y.yaml` / `lazy_vX.Y.min.yaml`。

何时归档：升号时把**上一个版本**存进来。归档由 `skill/scripts/clash/build_profiles.py --archive` 执行。

⚠️ 归档文件里的 URL 指向本仓（自包含优先 —— 代价是归档不再忠实于发布当时的绝对地址，刻意如此。

当前状态：mihomo 版本线从 v1.0 起，尚无历史版本 ⇒ 目录暂空。首次升号（v1.1）时把 v1.0 存进来。
